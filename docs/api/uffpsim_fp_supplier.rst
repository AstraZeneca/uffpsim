Fingerprint Supplier (Serial) Module
=====================================

.. currentmodule:: uffpsim.fp_supplier

Module Overview
---------------

The FP supplier module provides serial fingerprint generation utilities for reading molecular data from files or iterables and computing fingerprints one molecule at a time.
